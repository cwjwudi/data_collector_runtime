配置文件

选择一个完整 config 文件进行加载；每个文件包含基础设置、查询视图和插件页面配置。

数据库设定

数据库与查询限制写入 app_settings。点「保存数据库设定」保存。

数据库连接

MySQL / SQLite 连接参数（app_settings.database）

查询限制

API 限流与时间窗口（app_settings.query_limits）

OPCUA设定

连接信息、全局轮询间隔与心跳写入 profile 顶层 opcua。 心跳按轮询间隔写 1（仅 BOOL / 整型）；PLC 清 0/FALSE，超时未再变 1 则判定 Query Web 挂了。

连接

分别填写 PLC 的 IP 与端口（无需写 opc.tcp:// 前缀）

留空默认 127.0.0.1:4840

监控与心跳（全局）

作用于全局 OPC 轮询与心跳写入；心跳仅支持 BOOL / 整型，写 1

范围 50–5000，默认 500

Group 与列

配置各表的时间字段、批次号绑定字段、列顺序、排序、分页与列中英文显示名；仅在查询中引用已配置的组。

批次号选项来源（View 级）

决定查询页下拉框从哪张表、哪个字段读取；留空表示禁用批次号查询。

可选列
查询列顺序（最终生效）
列显示名编辑

插件页面

用于 /plugins/{module}_{1-5}.html 动态绑定；每模块预留 1–5 页。

OPC UA 回写

勾选需要回写的列并填写 NodeId（B&R 示例：ns=6;s=::DataRev:strStartTime）； 仅白名单列写入 PLC 数组（最长 50）。全局 Endpoint 在「基础设定」中配置。

翻页/查询后写 -1；点击行写 0–49
高级 · opcua_writeback JSON 预览

只读预览，由上方表单生成；保存当前页配置时以表单为准。 columns 键为数据库字段名，未列出的列不会写 PLC。

OPC UA 翻页 / 批次表名回写

基础模式根据 diCursor 选中行写批次表名数组；高级模式可只配置上一页/下一页， 也可额外配置批次号与触发节点执行批次表名回写。

可选；不选则按批次号反查主表
高级模式仅翻页时可留空

高级 · OPC UA 节点

上一页/下一页为独立可选的 BOOL 节点（上升沿触发）。仅使用翻页时，批次号 NodeId、触发 NodeId、Buffer NodeId 均可留空； 如需批次表名回写，则批次号与触发节点必须成对填写，并配置 Buffer。 轮询间隔与心跳在上方「OPCUA设定」中全局配置。

高级 · table_list_writeback JSON 预览

只读预览；保存当前页配置时以表单为准，可在此复制后手动合并高级字段。
